Do not sacrifice usability for visual effects.

# PERFORMANCE

The website should feel fast and responsive.

Avoid unnecessary:

* Huge image assets
* Heavy animation libraries
* Video backgrounds
* Excessive JavaScript interactions
* Unoptimized images
* Decorative elements that negatively affect loading

Visual richness should not compromise performance.

# CASE STUDY DESIGN PRINCIPLE

The detailed UX case study should contain the deeper process.

The main portfolio page should NOT become a research report.

For each full case study, structure the deeper experience around relevant content such as:

**Overview → Problem → Research → Insights → UX Approach → User Flows → Wireframes → Design Reasoning → UI → Design System → Iteration → Outcome → Key Takeaway**

Only include sections for which real content exists.

Do not force every case study into an identical template.

The case study should demonstrate:

**What was the problem?**

**What did I understand?**

**What did I decide?**

**Why did I design it this way?**

**How did the final product solve the problem?**

This is more important than simply displaying a sequence of screens.

# HOMEPAGE CONTENT DENSITY

The homepage must be highly scannable.

Do not place the complete research process of every project on the homepage.

The homepage is the **discovery layer**.

The expanded View More section is the **project understanding layer**.

The Case Study is the **deep UX thinking layer**.

The live project is the **product experience layer**.

Therefore the portfolio has three levels:

**Quick Overview → Understand the Product → Explore Product / UX Process**

Keep this hierarchy extremely clear.
